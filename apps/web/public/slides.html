The problem

Disconnected evidence

Learning is sequential. Project evidence often is not.

01

Work is left behind

A student builds an application, submits it, and moves to the next module.

02

Fit is hard to judge

The next lecturer may lack a clear view of what that project demonstrates.

03

Gaps surface late

Programme leaders need earlier signals about skills that may remain under-covered.

The opportunity: review the evidence before deciding whether to start again.

Build on prior learning when it fits the next module02 / 07
The solution

One connected review flow

Three work areas turn evidence into a decision.

1

Review sources

Inspect coursework and project evidence. Confirm candidate data before it informs a prediction.

2

Check project reuse

Compare an existing project with a future module's goals, required skills, and assignment context.

3

Forecast skill gaps

See illustrative graduation coverage, then explore a possible action under an explicit gain assumption.

BuildForward presents evidence and a suggestion. The educator decides what to do.
