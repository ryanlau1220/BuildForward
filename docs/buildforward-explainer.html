BuildForward links reviewed learning inputs to two questions: can an existing student project be reused and extended in a future module, and which skills may need more attention before a student intake graduates?

PAGE 02 · STUDENT INTAKE VIEW

Graduation Skills Forecast

This page looks across a student intake and the remaining curriculum. It estimates which skills may still be below an illustrative target by graduation.

  • Current coverage is compared with a projection from future modules.
  • Some gaps have a DOSM occupation-demand signal linked by BuildForward's skill mapping to help order review.
  • When project and module evidence align, BuildForward suggests an educator action to review; the scenario slider tests a separate gain assumption you choose.
DOSM counted 19,899 Software Developer online offerings in Q2 2026. BuildForward's skill links are separate interpretations, not measured skill demand.

What the demo can and cannot tell you

Project Reuse Check uses a classifier trained on synthetic rubric scenarios. The Graduation Skills Forecast uses simulated student-intake coverage and fixed demonstration assumptions. A deterministic action suggestion appears only when the project, module and skill-gap evidence align; an educator reviews it and decides what to do. The slider explores an assumed effect, not a predicted one.
