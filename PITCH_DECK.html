How We Built It

Real & curated sourcesCurriculum, assignments, GitHub artifacts, market signals.

Evidence extractionStatic repository analysis, provenance, confirmed facts.

Feature pipelineCompetency overlap, prerequisites, reuse signals, coverage gaps.

Predict + explainContinuity classifier, cohort forecast, ranked recommendations.

BuildForward recommends. Programme leaders and lecturers decide. No automatic curriculum changes, no LMS execution, no agent workflow.
